## What landed

**Plan 001** — `vitest` + `vitest.config.ts` + `npm test`; `@types/node` bumped
20 → 26 (vitest 5 requires ≥22, and `.node-version` pins Node 26); lint green
(vendored `.agents/`, `.claude/`, `skills/` trees ignored).

**Plan 002** — `USER_ROLES` is the API's six roles; `CAPABILITIES` is the single
role→capability map; every workspace guard and redirect updated; the user form
offers only the four assignable roles.

**Plan 003** — 26 API paths re-pointed (`/clients`→`/customers`,
`/visits`→`/queue-sessions`, `/referrals`→`/service-transfers`,
`/clinical/call-next`→`/queue/call-next`, export path). `lib/api/routes.test.ts`
scans for retired prefixes.

**Plan 004** — `VerifiedUser` now carries `facility_ids`/`station_id` (the real
`/auth/me` shape); department is derived from the user's station; `LiveRefresh`
subscribes to the facility-scoped **public** channel the API actually broadcasts.

**Plan 005** — station types are the backend's `INTAKE|SERVICE|CASHIER|COUNTER`;
customer/registration payloads match `CustomerController` and
`ReceptionController::completeRegistration` (`customer_id`/`customer_data`); the
kiosk booking preview matches `IntakeService::lookupOnlineBooking`
(`customer_preview`, `session_number`); the tracking payload matches
`QueueSessionService::getTrackingData` (`queue_session`, `customer`,
`service_transfers`). `lib/vocabulary.test.ts` fails the build on clinical
vocabulary.

**Plan 006** — `components/facility-switcher.tsx` + `lib/facility/selection.ts`
(pure, tested) + `lib/facility/{context,server,actions}.ts`. The server fetch and
both proxies send `X-Facility-Id`; the value is always re-validated against the
account's `facility_ids`. `POST /auth/register` sends `X-Tenant-Slug` from
`NEXT_PUBLIC_TENANT_SLUG`.

## Findings considered and rejected

- **`skipLibCheck: true` + `allowJs: true`** — standard Next defaults.
- **`react-hooks/set-state-in-effect` downgraded to `"warn"`** — documented
  rationale in `eslint.config.mjs`; the fetch-on-mount + reset pattern is
  intentional in every workspace hook.
- **Committed secrets** — none. `.env`/`.env.local` are untracked and gitignored.
- **`cn` package vs `clsx`+`tailwind-merge`** — official shadcn-ui replacement,
  already the convention.
- **`/broadcasting/auth` missing** — false finding; the route exists. Private
  channels are still unreachable from the browser because Echo cannot attach the
  HttpOnly token, so the public facility channel is the correct path.
- **Six separate HTTP clients** — unification touches every data path for no
  user-visible gain while the refactor is in flight.
- **`shadcn` CLI in `dependencies`** — cosmetic; one-line move to devDependencies.
